# Bundled Source Han fonts

Official Adobe Source Han variable fonts, unmodified WOFF2 region subsets.
CN is Simplified Chinese; JP is Japanese. Each family falls back to its other region for mixed text.
Fonts load locally on selection; no external font service is required for these four options.
