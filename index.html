Help / 帮助

Quick Start / 快速开始

Upload a PNG, JPG, WebP, or SVG. Use Brightness for normal images, Alpha for transparent logos. 导入图片后选择亮度或透明度作为高度来源。

Relief / 浮雕

Height controls depth, Edge softness smooths edges, Base cut removes faint background, Edge swell adds raised bevel. 调节高度、柔边、底部裁切和边缘膨胀。

Composition / 构图

Single is for one centered image. Mosaic blends multiple panels into one relief board. Drag the preview to move light. Single 适合单图，Mosaic 适合多图拼版。

Material / 材质

Choose a preset first, then fine tune color, grain, roughness, highlight, and surface texture. 先选预设，再微调颜色、颗粒和反光。

Overlay / 叠加

Overlay keeps a PNG/WebP/SVG above the relief. Drag it on canvas, use mouse wheel or Scale to resize, Clear returns to Blank. 叠加图可拖动、缩放和清空。

Export / 导出

PNG supports 1x, 2x, 4x, and Custom long-edge export. Export Light Sweep records a short WebM light animation. PNG 支持 1x、2x、4x 和自定义长边导出。
